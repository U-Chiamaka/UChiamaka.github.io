Projects

Data Projects

USDA Pricing Data Analysis

Analyzed USDA agricultural pricing data using Power BI to explore price trends, identify high- and low-priced commodities, and build interactive visualizations for comparing pricing patterns. The analysis provided actionable insights into pricing dynamics for better decision-making in the agricultural sector.

Online Learning Data Analysis

Explored online learning trends across Spain, India, and France from 2004-2021. Using Python and Plotly, analyzing growth patterns, identified peak years, and visualized regional differences in adoption rates. The insights highlight the evolution of e-learning globally and provide a foundation for understanding future trends in digital education.

Supermarket Sales Analysis

This project analyzes supermarket transaction data from Aries branches in Lagos, Abuja, and Port Harcourt using Python and Pandas. I explored sales performance, product lines, customer behaviour, payment preferences, customer ratings, and purchasing patterns, using data cleaning, exploratory analysis, and visualizations to generate actionable business insights.

Perfume E-Commerce Sales Analysis

This project involved analyzing perfume sales data using Python, SQL, and Power BI to uncover key trends and insights. I explored revenue, stock availability, best-selling products, and brand performance for both gender categories. The analysis highlighted sales dynamics and provided actionable recommendations for optimizing inventory and marketing strategies.
